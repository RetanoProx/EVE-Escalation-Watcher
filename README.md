# EVE Escalation Watcher

Локальний Windows-застосунок для відстеження експедицій в грі Eve online.

## Використання

1. Скачайте останню версію програми в Releases і розпакуйте архів (EXE'шник і папку з налаштуваннями) у зручну для вас папку.
2. Запустіть `EVE-Escalation-Watcher.exe`.
3. Оберіть мову у списку **Мова** та тему у списку **Тема**. Українська мова й світла тема використовуються за замовчуванням; вибір зберігається для наступних запусків.
4. Каталог систем EVE завантажується автоматично під час першого запуску та зберігається поруч із застосунком у `eve_watcher_data`. Після цього використовується локальна копія.
5. Введіть або вставте назву домашньої системи через **Ctrl+V**.
6. Натисніть **Джамп-бриджі…**, вставте актуальний список рядків у форматі `SYSTEM-A -> SYSTEM-B` і натисніть **Зберегти й замінити**. Список зберігається в `eve_watcher_data\jump_bridges.json` до наступної ручної заміни. Кожен зв’язок двосторонній та рахується як 1 стрибок.
7. Один раз натисніть **Папка логів…** і виберіть EVE-папку `Chatlogs` (наприклад, `C:\Users\Retano\Documents\EVE\logs\Chatlogs`). Шлях зберігається для наступних запусків.
8. Залиште радіус `5` і натисніть **Запустити**.

Програма автоматично відстежує лише файли з іменем `Imperium Expeditions_*.txt`, ігноруючи логи інших каналів. Щосекунди вона обирає найновіший відповідний файл, тому перемикається на новий файл чату одразу після його створення. У панелі потоку чату відображаються нові рядки використаного файлу та його ім’я.

Після запуску старі рядки не обробляються: застосунок стежить лише за новими повідомленнями. Сповіщення визначається за назвою системи — ключові слова продажу не потрібні. Якщо в одному повідомленні вказано кілька систем у заданому радіусі, для кожної з них додається окремий запис. Повідомлення про купівлю відсіюється, якщо після системи (опціонально через символи `*`) йде шаблон `пробіл + x/х у будь-якому регістрі`, а далі пробіл, кінець повідомлення, крапка або кома: `LK1K-5 x 150m`, `0-VG7A* х`, `LK1K-5 Х.` чи `0-VG7A** x,`. Інші входження літер `x` або `х` не впливають на обробку оголошення про продаж.

Відстань - мінімальна кількість переходів **через stargates** за даними SDE. Jump bridges враховуються якщо ви їх попередньо завантажити. По замовчуванні завантажені джампбриджі Імперіуму. Wormholes, filaments і тимчасові ігрові ефекти не враховуються.

Джерело SDE: https://www.fuzzwork.co.uk/dump/latest/csv/ (`mapSolarSystems.csv`, `mapSolarSystemJumps.csv`).
