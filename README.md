# EVE Escalation Watcher

Локальний Windows-застосунок для відстеження лог-файлу каналу **Imperium Expeditions**.

## Використання

1. Запустіть `EVE-Escalation-Watcher.exe`.
2. Оберіть мову у списку **Мова**: українська використовується за замовчуванням, англійська доступна як альтернатива. Вибір зберігається для наступних запусків.
3. Каталог систем EVE завантажується автоматично під час першого запуску та зберігається поруч із застосунком у `eve_watcher_data`. Після цього використовується локальна копія.
4. Введіть або вставте назву домашньої системи через **Ctrl+V**.
5. Натисніть **Джамп-бриджі…**, вставте актуальний список рядків у форматі `SYSTEM-A -> SYSTEM-B` і натисніть **Зберегти й замінити**. Список зберігається в `eve_watcher_data\jump_bridges.json` до наступної ручної заміни. Кожен зв’язок двосторонній та рахується як 1 стрибок.
6. Один раз натисніть **Папка логів…** і виберіть EVE-папку `Chatlogs` (наприклад, `C:\Users\Retano\Documents\EVE\logs\Chatlogs`). Шлях зберігається для наступних запусків.
7. Залиште радіус `5` і натисніть **Запустити**.

Програма автоматично відстежує лише файли з іменем `Imperium Expeditions_*.txt`, ігноруючи логи інших каналів. Щосекунди вона обирає найновіший відповідний файл, тому перемикається на новий файл чату одразу після його створення. У панелі потоку чату відображаються нові рядки використаного файлу та його ім’я.

Після запуску старі рядки не обробляються: застосунок стежить лише за новими повідомленнями. Сповіщення визначається за назвою системи — ключові слова продажу не потрібні. Якщо в одному повідомленні вказано кілька систем у заданому радіусі, для кожної з них додається окремий запис. Повідомлення про купівлю відсіюється лише для конкретної системи, після якої стоїть **саме** шаблон ` пробіл + x/х + пробіл`, наприклад `LK1K-5 x 150m` або `LK1K-5 х 150m`. Інші входження літер `x` або `х` не впливають на обробку оголошення про продаж.

Відстань — мінімальна кількість переходів **через stargates** за даними SDE. Jump bridges, wormholes, filaments і тимчасові ігрові ефекти не враховуються.

## Portable EXE

Готова збірка розміщується у `dist\EVE-Escalation-Watcher.exe`. Поруч із нею створюється папка `eve_watcher_data`; її потрібно залишити поряд з EXE, якщо хочете передати користувачу налаштування, звукове сповіщення та вже завантажений каталог без повторного завантаження.

Щоб поділитися програмою, запакуйте в ZIP увесь вміст папки `dist`. Для приватності перед надсиланням можна видалити `eve_watcher_data\settings.json`: у ньому зберігаються ваші шлях до логів, домашня система та інші персональні налаштування.

Для збірки у Windows запустіть `build.bat`. Python потрібен лише на комп’ютері збирача; користувачам готового EXE Python не потрібен.
